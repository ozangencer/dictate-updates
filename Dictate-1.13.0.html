Fixed

  • Downloading a Whisper model failed instantly. Two entries in the model catalogue named folders that do not exist in the WhisperKit model repository, so pressing Download on the recommended model threw an error before a single byte was fetched. The ids are corrected, the listed sizes are now what is actually downloaded, and a failed download says so on screen instead of failing silently.
  • A meeting could be filed and titled after the wrong calendar event. The start time was worked out by subtracting the audio's length from the file's timestamp, which is only right when the recording captured audio the whole time. A call whose microphone died mid-meeting was filed two hours late and named after an unrelated appointment. The start is now read from the recording itself.
  • A recording nothing was reaching kept running. When every capture source has delivered silence for fifteen minutes, the recording now stops and saves what it has. This is not a time limit — long meetings are unaffected.

Improved

  • Save a transcript in several formats at once. Plain text, subtitles, JSON and meeting minutes are four renderings of one transcription, so the Output Format list is now multiple choice. Only meeting minutes costs anything, and it costs the same whether it is saved alone or beside the other three.
  • Speaker names can be reused. Diarization often splits one person across two labels, and giving both the same name is how they are merged — but the name was removed from the suggestion list once it had been used. Used names now appear under "Already assigned" and can be picked again.
  • Merged speakers now have merged segments. Naming two labels as the same person used to leave their lines separate in the saved transcript.
